# Полный цикл высокопроизводительной СТ-реконструкции на CPU: Архитектура и реализация

**Аннотация**  
В данной статье представлено комплексное описание конвейера фильтрующей обратной проекции (Filtered Backprojection, FBP), реализованного в проекте QtCTReconstruction. Рассматриваются все этапы: от генерации синограмм до финальной 3D-реконструкции, с детальным анализом программных оптимизаций для современных многоядерных процессоров.

## 2. Этап 1: Генерация синограмм (Преобразование Радона)

Для ускорения прямого проецирования используется стратегия пакетирования углов (**Angle Batching**), аналогичная той, что применяется в обратной проекции.

### Оптимизация: Пакетная тригонометрия
Вместо вычисления `cos` и `sin` для каждого пикселя, мы вычисляем их один раз для пакета из 16 углов.

```cpp
// Фрагмент из RadonTransform.cpp
const int batch_size = 16;
for (int b_start = 0; b_start < na; b_start += batch_size) {
    float b_cos[16], b_sin[16], b_u_base[16];
    for (int b = 0; b < b_count; ++b) {
        float th = utils::degToRad(...);
        b_cos[b] = std::cos(th); // Вычисляем один раз на пакет
        b_sin[b] = std::sin(th);
        b_u_base[b] = -cx * b_cos[b] + cy * b_sin[b] + detector_center;
    }
    // ... обработка пикселей для 16 углов одновременно ...
}
```
**Результат:** Математический блок CPU загружен эффективно, а количество вызовов тяжелых тригонометрических функций сокращено в 16 раз.

---

## 3. Этап 2: Фильтрация в частотной области

Без фильтрации обратная проекция дает размытое изображение («эффект звезды»). Мы используем фильтр Рам-Лак (Ram-Lak) в спектральной области.

### Оптимизация: Параллельное БПФ (FFT)
Фильтрация каждой проекции независима, что позволяет распараллелить процесс по углам.

```cpp
// Фрагмент из FilteredBackprojection.cpp
#pragma omp parallel for schedule(dynamic)
for (int a = 0; a < na; ++a) {
    // 1. Forward FFT
    auto spectrum = FFT::forward(proj_padded);
    
    // 2. Спектральное умножение на фильтр
    for (size_t k = 0; k < spectrum.size(); ++k) {
        spectrum[k] *= static_cast<double>(filter[k]);
    }
    
    // 3. Inverse FFT
    const auto q = FFT::inverse(spectrum);
    // ... сохранение результата ...
}
```
**Техническая деталь:** Перед БПФ данные дополняются нулями (**Zero Padding**) до ближайшей степени двойки. Это предотвращает артефакты циклической свертки и позволяет использовать самый быстрый алгоритм БПФ.

## 4. Этап 3: 3D-реконструкция (Обратная проекция)

Это самый тяжелый этап, на который тратится 90% времени. Мы используем две ключевые стратегии: **Project Reactor** и **Project Refinery**.

### 4.1. Project Reactor (L1 Cache Efficiency)
Мы удерживаем рабочую строку объема в L1 кэше (32КБ), прогоняя через неё 16 проекций.

```cpp
// Фрагмент из OptimizedBackprojectionCPU.cpp
for (int p_start = 0; p_start < total_projections; p_start += 16) {
    // Пакет углов p...p+15
    for (int p = p_start; p < p_end; ++p) {
        // Мы читаем из DDR проекцию (row_p), 
        // но пишем в vol_row_p, которая УЖЕ в кэше L1 от предыдущего угла p-1
        for (int x = x_start; x < x_end; ++x) {
            vol_row_p[x] += row_p[u0] + fu * (row_p[u0+1] - row_p[u0]);
        }
    }
}
```
**Результат:** Нагрузка на шину памяти RAM снижена в 16 раз. Процессор не ждет данных из медленной памяти при каждой записи.

### 4.2. Project Refinery (SIMD & Branch-Free)
Мы полностью убрали проверки `if` из внутреннего цикла, рассчитав границы `x_start/x_end` заранее.

```cpp
// Вынос границ (Hoisting)
int x_start = std::max(0, static_cast<int>(std::ceil(xs)));
int x_end = std::min(nx, static_cast<int>(std::floor(xe)));

// Теперь компилятор может использовать 256-битные AVX инструкции
#pragma omp simd
for (int x = x_start; x < x_end; ++x) {
    const int u0 = static_cast<int>(u);
    const float fu = u - static_cast<float>(u0);
    // Математика без ветвлений
    vol_row_p[x] += ...;
    u += du; // Инкремент вместо умножения
}
```
